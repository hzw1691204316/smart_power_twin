## 数据与主要代码

复用现有阿里云DataV.GeoAtlas中国省级数据，按adcode生成34份局部边界及省级目录，没有增加外部请求依赖。

- public/maps/province-index.json：省名、编码、镜头范围及本地边界地址。
- public/maps/provinces/*.geojson：独立省级轮廓。
- scripts/prepare-province-outlines.mjs：从现有全国边界重新生成。
- src/views/ProvinceMapView.vue：其他省级区域页面。
- src/utils/provinceCatalog.ts：省域路径和定位范围。
- src/components/map/cameraView.ts：自适应相机距离。
