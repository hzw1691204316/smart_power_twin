# 河南全省与地市高速路网：最新续接记录

更新日期：2026-10-13。本文是当前版本最新记录，省域与市域数量、行为以本文为准。

## 本轮用户要求

用户反馈从中国地图进入河南后不像河南高速图，并要求继续按市划分高速路线。所有修改仍限定smart_power_web前端，未修改后端、数据库、Cesium Token或第四版GLB。

## 已实现的页面层级

中国/overview → 河南全省/province/henan → 地市/province/henan/cities/:cityCode → 站点/sites/:siteId。

- 河南全省页可直接点击地市区域或市名进入，也可在地图上方下拉框选择地市。
- 覆盖现有公开数据中的18个市级区域，含济源。
- 市域页面自动定位该市范围，突出所选市边界，只显示该市裁剪后的高速路段与已归属设施点。
- 可通过“返回河南全省”或下拉框中的河南全省退出市域。
- 从市域进入三维样板时保留cityCode查询参数，返回按钮回到对应市域。
- 没有演示样板的市仍能查看公开路网与设施，不能把公开点直接当作已接入电力的三维站点。

## 河南路网显示的修订

1. 全省高速线进一步与现有18个市界合并后的省域边界相交裁剪，清除省域外延伸，当前416条展示折线。数量变化来自裁剪，不等于实际高速路线数量变化。
2. 市域不是按外接矩形粗选，也不是只放大地图。对跨市高速进行几何相交裁剪，每个市单独生成GeoJSON。
3. 高速线设为可控显示高度，避免与行政区填色同面；全省线宽3，市域线宽4，路线标签在较高层显示。
4. 各市公开设施通过点与市界的包含关系分配cityCode。目前826个公开设施有归属，18个未能归属的点保留在源文件但暂不显示，等待坐标及边界核验。
5. 已检查5173端口对应进程路径，为用户指定的smart_power_web项目，排除了打开此前旧原型的可能。

此前“效果不对”的实际画面仍没有浏览器截图，因此不能声称已最终确定唯一原因。当前修复覆盖了视野层级、几何范围和路线可见性问题；用户刷新后仍需实际确认。
