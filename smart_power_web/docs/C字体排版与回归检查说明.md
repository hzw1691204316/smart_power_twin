## 字体与排版改进

统一规则位于 `src/styles/typography.css`，在海蓝主题之后加载，主要调整文字，不重写地图或大屏布局。

| 用途 | 规则 |
|---|---|
| 中文正文、标题、按钮 | 优先本机HarmonyOS Sans SC，回退到Segoe UI及微软雅黑UI等系统字体；中文按可用字形回退 |
| 指标和时钟数字 | 优先Bahnschrift，回退到Segoe UI；统一等宽数字特性与字重 |
| 标题 | 适度加重、缩小过大的字距，保持清晰层级 |
| 站点名称、测点说明 | 提高字号和行高，长名称允许换行 |
| 侧栏统计 | 根据窗口调整数字大小，数字与单位允许换行，减少窄侧栏溢出 |
| 地图内部文字 | Cesium Canvas标签读取同一套UI字体，避免与页面割裂 |

已核对本机Windows字体文件包含Bahnschrift、Segoe UI、微软雅黑。没有假定本机已经安装鸿蒙字体，也未安装或打包分发额外字体；无需用户另装字体即可生效。

渲染效果会随操作系统、缩放比例及可用字体变化。更换字体不改变原有数字、单位和演示数据口径。

## 固定检查流程

开始下一轮修改前：

```powershell
npm.cmd run check:regression
```

完成修改后：

```powershell
npm.cmd run verify
```

verify依次执行代码检查、关键回归检查和类型/生产构建。任一步失败会停止后续步骤，修复后再收尾。此命令沿用项目现有lint的自动修复行为。

## 每次收尾的页面检查

1. 全国、河南和地市页：标题是否仍在统一页头，统计是否仍位于左右框内。
2. 配色和地图：海蓝主题、立体/俯视切换、道路和设施点是否保留。
3. 导航：省市下钻、黄色/绿色点进入正确类型三维、返回原入口与筛选条件。
4. 模型：朝歌配对仍正确，第四版GLB仍可定位设备；公开模板和演示数据继续明确标注。
5. 文字：标题、站点名称、数字和单位有没有挤出卡片；说明是否可读。
6. 异常及窄屏：空结果、加载失败、离线值、侧栏滚动与小屏布局。

自动检查验证代码结构、资源和逻辑，不能证明实际画面已通过视觉验收。当前本地浏览器预览仍受此前保存策略限制，本轮未取得新的浏览器截图；真实字体观感、缩放与间距仍需刷新页面验收。
