# 地图三角斑纹修复说明

日期：2026-10-14。

## 原因与修复

用户截图中的三角斑纹与上一轮新增底座有关：原底座使用挤出Polygon，默认包含水平顶盖。全国地图表面高度32000m，底座顶盖31980m，两层大范围表面仅隔20m，在远距离显示时容易争抢深度，呈现三角状破面。厚度数值仅用于展示，不是实际海拔。

本次改为Cesium WallGraphics，仅沿边界绘制深色垂直侧壁，彻底移除第二个水平顶盖，地图只保留一个顶面。侧壁闭合边界且不修改原始坐标数组。卫星底图下仍按原逻辑隐藏侧壁。

改动覆盖全国、河南与其他省级区域共用的行政图层；行政细暗线、高速明亮实线、设施颜色、34省入口、地图视角及页面布局继续保留。

## 验证

`npm.cmd run verify` 已通过代码、回归、类型及生产构建检查。

新增检查调用Cesium实际WallGeometry几何生成器，在120m、450m、3500m和32000m展示厚度下，验证每个三角形都跨越侧壁上下高度，不存在与地图表面重叠的水平盖面；同时检查边界闭合、输入坐标不被修改和无效输入处理。

继续核对时新增 `npm.cmd run check:map-layers`，在不启动浏览器的情况下运行真实行政区与道路图层构建，覆盖全国、河南省域、鹤壁市域的高度模式及山东省轮廓。确认底座数据源没有Polygon盖面、顶面未重复挤出、蓝图/卫星切换正确隐藏并恢复侧壁，以及高速仍采用实线暗描边并可筛选。该检查已加入verify。

实际浏览器尚未取得新的截图。本轮代码和几何检查说明已移除导致冲突的结构，但不把它们当作视觉验收。刷新全国地图后应重点核对新疆、西藏等大区域是否还有斑纹，再检查河南道路与省界是否仍清楚。
