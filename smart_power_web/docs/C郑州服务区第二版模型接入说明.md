## 如何查看
1. 启动原有前后端，正常登录。
2. 进入“河南路网”，在“地图设置→地市路网”选择“郑州市”。
3. 站点检索切换到“公开位置”，搜索“郑州服务区”，点击对应绿色地图点进入三维。
4. 或登录后访问：`http://127.0.0.1:5173/facilities/osm-1317836742?origin=410100`。
5. 三维界面左侧可选择光伏、储能、配电、充电设备；点击列表后使用“定位当前设备”，也可直接点击模型。点击“返回路网”返回郑州市；从全省进入则返回全省。

若页面打开的是其他服务区，请核对名称与设施ID。原模型文件名未复用，避免浏览器沿用旧资源缓存。
