# 省份地图滚轮缩放修复说明

日期：2026-10-14。

## 需求与处理

用户反馈省份地图滚轮放大时倾斜，并明确只修改省份地图。全国地图的外观、视角和原滚轮交互保留。

检查本地Cesium源码发现，默认三维缩放会根据鼠标位置选择目标，并在部分高度范围调整相机方向。原先关闭enableTilt只限制倾斜手势，不能禁止缩放内部的方向调整。

本次仅对河南省、河南市域下钻和其他省份页替换滚轮输入：沿当前画面中心方向前进或后退，同时显式保留相机的当地朝向、俯仰角和横滚角。滚轮不会自动切换为俯视；原“立体／俯视”按钮继续决定视角。右键缩放和触屏双指仍使用原Cesium行为。

缩放步长随当前离地距离变化，并限制单次步长；镜头最低距离抬高后的地图表面500m，避免连续滚轮穿入地图。原地图点击、拖动、站点定位和全域视野功能保留。

## 修改文件

- `src/components/map/mapWheelZoom.ts`：省市滚轮配置与固定角度缩放。
- `src/components/map/CesiumMap.vue`：绑定输入；随已有事件处理器一起销毁。
- `scripts/check-map-layers.mjs`：使用真实Cesium Camera执行连续缩放测试。
- `AGENTS.md`：记录全国与省市滚轮行为分别保留的要求。

## 检查结果

修改前原回归通过；修改后 `npm.cmd run verify` 全部通过，包括代码检查、原功能回归、图层检查、类型检查和生产构建。

真实Camera检查覆盖河南省倾斜视角、河南市域俯视、其他省份倾斜视角，每种连续放大140次、缩小140次：俯仰角及朝向保持，镜头高度在限制内；零值、非有限滚轮输入和禁用交互时不移动。确认全国没有绑定新滚轮事件，原缩放配置未改。全国发光省界、省市路网、侧壁无顶盖、卫星切换和高速筛选检查继续通过。

本轮没有新的浏览器视觉验收。刷新河南省页面后，可分别在立体、俯视模式下连续滚轮检查，再回全国确认原效果保持。代码和相机数值检查不能替代真实交互验收。
