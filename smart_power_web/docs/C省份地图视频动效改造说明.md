## 1. 本次采用的效果

参考用户提供的 MP4：前半段为有厚度的省域地图、底部环形流光与镜头环绕；后半段为带光柱的三维数据地图。本次借用这些表现方式，保持系统现有海蓝底色、青蓝路线、绿色服务区和黄色收费设施。

只替换省份和河南地市的旧立体方案。全国中国地图保留原有高度、发光省界、河南高亮、相机适配和滚轮行为；收费站/服务区的第四版 GLB 模型、登录账号逻辑和后端未修改。

省份新效果包括：

- 连续厚底座：沿省域外缘绘制三段深浅蓝色侧壁，内部市界不再逐市挤出侧壁。
- 单一平整顶面：不叠加第二个水平顶盖，避免之前出现的三角斑纹。
- 底部环形舞台：两条淡蓝装饰环、一段沿环移动的青蓝流光，与高速路线分开。
- 轻缓往复环绕：围绕区域中心左右各约 12° 缓慢运动，保持目标俯仰和距离，减少旋转时地图越出可视区。并非无限整圈自动旋转。
- 样板光柱：最多六个已授权三维样板加少量脉动光柱；不把全部公开设施变成密集光柱，不用高度表达未接入的真实电力数值。其他省域没有已授权样板时不生成虚构站点光柱。

高速线路仍为清晰实线，市界仍为低对比细线；不会用发光市界替代高速线。

## 2. 页面如何操作

1. 正常登录后，从全国图点击河南，或从顶部进入河南路网。
2. 蓝图的立体模式默认播放动态展示。左侧“地图设置”增加“动态展示”开关。
3. 在地图上按下鼠标、拖动、触摸或滚轮缩放时，自动环绕暂停；流光继续播放。不会过几秒自动抢回镜头。
4. 地图下方“继续环绕”会回到当前省/市全域视野，再开始环绕；“暂停环绕”只暂停镜头。
5. 取消“动态展示”关闭装饰和自动环绕；切换俯视或卫星时同样停止动效，切回后可恢复。
6. 绿色/黄色点继续进入对应三维场景。点击识别会穿过装饰图层，不让流光或光柱挡住业务入口。
7. 系统启用“减少动态效果”时自动不播放。切换到后台标签页停帧，返回时接着播放，离开地图页清理循环及事件监听。

不新增横排统计卡、重复地图标题、底部说明栏。既有左右半透明面板、地图铺满工作区、收起面板、字体、供应商署名均保留。

## 3. 代码模块与参数

| 文件 | 职责 / 可以修改什么 |
| --- | --- |
| `src/components/map/administrativeLayer.ts` | 全国/省域行政图层分支。省市底座只沿外缘拼接三段垂直侧壁；底座随卫星主题隐藏。 |
| `src/components/map/regionSideWall.ts` | 生成无水平顶盖的侧壁。`height` 和 `bottom` 为上下展示高度，单位米；全国继续使用默认 `bottom=0`。 |
| `src/config/mapPresentation.ts` | 展示高度：河南省 18000 米、地市 2600 米，其他省份按范围适配。是视觉厚度，不是真实海拔。全国仍为 32000 米。 |
| `src/components/map/provinceDynamics.ts` | 独立环形流光、样板光柱、相机环绕；不读取数据库或生成业务统计。 |
| `src/components/map/CesiumMap.vue` | 接入动效、限帧、鼠标暂停、隐藏页停帧和卸载清理；全国不创建动效图层。 |
| `src/components/map/MapDisplayControls.vue` | 左侧动态展示开关。 |
| `src/views/ProvinceView.vue` / `ProvinceMapView.vue` | 河南省/地市与其他省域共用动态设置，保持原有业务和路由。 |
| `src/styles/map.css` | 小型暂停/继续环绕按钮样式，不改整体主题。 |

`provinceDynamics.ts` 中的主要调节项：

- `Math.PI / 15`：环绕最大偏角，约 12°。
- `/ 28`：往复环绕速度，完整来回约 176 秒；数值越大越慢。
- `seconds * 0.22`：底部流光角速度，完整一圈约 29 秒。
- `.slice(0, 6)`：光柱数量上限。
- `extent * 0.055`：光柱相对区域大小的高度，只是装饰高度。
- `DistanceDisplayCondition`：近距离找站时隐藏装饰光柱，防止遮挡。
- 页面循环最多 24 次/秒，动态几何最多更新 10 次/秒；不逐帧重建全省 826 个公开设施。
