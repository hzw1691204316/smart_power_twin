# C账号入口用户名显示说明

更新日期：2026-10-15

右上角原先使用用户的 `displayName`（显示名称），初始账号的显示名称包含“MySQL初始化…”字样，因此看起来像数据库登录提示。

现修改共享组件 `src/components/common/UserMenu.vue`，按钮改用 `auth.user.username` 显示实际登录用户名。例如使用 `mysql_admin` 登录时显示 `mysql_admin`，切换账号后随当前身份更新。

地图页和三维页共用该组件，账号菜单、账号管理权限判断、退出和刷新保持登录功能继续保留。没有修改数据库中的账号或显示名称，也没有恢复任何密码提示。

修改前回归检查通过，修改后完整 `npm.cmd run verify` 通过。实际浏览器视觉检查仍受此前本地预览权限限制，未完成。刷新页面即可加载新版本。
