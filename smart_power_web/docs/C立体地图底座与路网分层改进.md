# 立体地图底座与路网分层改进

日期：2026-10-14。

## 用户反馈与原因

全国及河南地图的立体轮廓杂乱，河南图中难以区分行政边界与高速。原实现每个区域都有顶部边线和底部发光线，顶面与侧面共用透明材质，行政边界选中时也发光，与高速叠加后容易形成多层线网。

## 本轮更换的方案

- 顶面：平整、不透明，以蓝色块面和轻微区域明暗区分行政区域。
- 底座：独立绘制深蓝实体，降低显示厚度。通过侧面明暗表现立体感，不再描画底部发光线。
- 行政边界：细、暗、无泛光；选中时适度改变颜色与线宽。
- 高速：明亮实线加细暗描边，不再用泛光扩散；国道高速与省级高速保留不同的浅蓝色。
- 背景：进一步减弱网格，避免背景线与业务线竞争。
- 图例：明确标注高速为明亮实线、行政边界为细暗线；服务区绿色点和收费设施黄色点保留。

全国显示厚度由65km减至32km，河南省域由6.5km减至3.5km，市域由1.2km减至0.45km；其他省域按自身范围降低厚度。上述高度仅为展示效果，不是实际海拔。道路、设施点和标签依旧位于表面上方。

## 保留与验证

保留全幅地图、半透明侧栏、较大字体、视角切换、地图复位、省市下钻、34个省级入口、路线筛选、设施点三维入口、朝歌模型绑定和返回逻辑。

修改前既有回归通过，修改后 `npm.cmd run verify` 通过代码检查、回归、类型与生产构建。补充检查道路颜色相对底面和行政边界的数值对比，帮助防止再次混淆；配色检查不能替代实际浏览器验收。

本轮没有新的自动浏览器截图，此前本地预览受保存的策略限制。刷新后重点查看：河南内部分界是否明显弱于高速；地图边缘是否只体现实体厚度而不出现双层亮线；选城市、筛选路线和点击设施是否继续正常。
