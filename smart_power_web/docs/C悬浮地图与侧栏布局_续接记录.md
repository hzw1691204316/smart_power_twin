# 悬浮地图与侧栏布局：续接记录

日期：2026-10-14。项目：`D:/study_software/PythonProject/smart_power_twin/smart_power_web`。

## 本轮改动

- 全国、河南及地市页共用MapWorkspaceLayout，桌面地图从页头下方铺到页面底部，覆盖原来整个三列工作区；左右信息框改为悬浮面板。
- 透明度仅作用于面板背景，文字不整体变淡；保留海蓝主题和圆角。
- 地图标题及显示设置移入左侧“地图设置”：展开后选择地市、底图、视角、道路/站点图层及全域复位。显示状态使用地图实际反馈。
- 服务区、收费设施、高速路线的图例放入右侧框，地图内部不再重复放标题、状态条、底图按钮和底部图例。
- 删除AppLayout中的FRONTEND WORKSPACE底栏。演示数据标识仍在页头和指标中；Cesium、OSM等地图署名继续保留，并移到侧栏之间。
- 移除Vite配置中注入页面的Vue DevTools浮动工具，避免底部继续出现白色V按钮；安装依赖保留，不影响业务组件。
- 增加“收起面板/显示面板”，可以查看侧栏覆盖的地图；收起不卸载地图或重置搜索条件。
- 地图页文字提高到13—17px左右，指标数字28—34px，省市和站点标签也相应放大。长说明折叠为“数据与模型说明”，给列表留空间。
- 1000px以下改为地图在上、信息框在下；650px以下单列，避免窄屏遮挡地图。

## 保留的功能

合并页头、侧栏四项统计、海蓝配色、立体/俯视、卫星底图、省市下钻、路线与站点筛选、黄色/绿色点进入三维、返回原层级、朝歌配对和第四版模型。

左侧控制组件与CesiumMap使用父页面同一份theme、tilted、showRoads、showSites，确保控件移动后仍与地图联动。主布局为页面级公共组件，减少全国与省市页漏改的机会。

## 验证与限制

修改前执行了既有回归检查。修改后代码检查、回归、类型检查和生产构建通过。检查覆盖原紧凑布局、图层高度、18市导航、公开模板和朝歌模型绑定。

实际浏览器画面仍待验收，此前本地预览受保存策略限制，本轮未取得自动浏览器截图。构建仍保留Cesium大包提示。

建议手动检查：

1. 刷新河南页，地图是否延伸到左右侧栏后方及页面底部。
2. 展开左侧“地图设置”，切换地市、底图、视角及图层，核对实际地图变化。
3. 点击绿色/黄色点进入三维，返回后核对原层级和搜索条件。
4. 收起并恢复面板，确认状态保留、地图署名未被遮挡。
5. 在1920×1080、1366×768及窄屏检查文字、侧栏滚动与列表空间。
