# 全国页紧凑布局与立体地图：完成及续接记录

日期：2026-10-14。

## 本次处理的问题

用户截图来自全国概览页。此前紧凑布局只应用于河南及地市路网页，全国页仍有独立标题行和四张横排指标卡；因此看起来像改动恢复了。本次将全国页一并统一，保留已确认的海蓝主题。

## 已完成的改动

1. 全国页的“全国能源运行概览”并入顶部品牌导航栏，移除单独占高度的标题区域。
2. “演示站点、可用演示站点”放入左侧省域工作空间；“示例总负荷、示例光伏出力”放入右侧能源观察框。保留数值和演示口径。
3. 全国、省域、地市页面使用一致的紧凑工作区：中央地图利用窗口剩余高度，左右侧栏可滚动；窄屏采用纵向布局。
4. 中国地图、河南与地市地图采用倾斜立体视角，行政区域有显示厚度，顶部边界与底部轮廓区分层次。地图厚度为视觉效果，不表示真实地形或海拔。
5. 道路、设施标记与标签的展示高度统一放在区域表面上方，避免立体区域遮住道路或站点。
6. 地图右下增加“立体视角/俯视视角”切换。全域复位、站点定位均使用相同的相机定位方式，倾斜后保持目标区域居中。
7. 减弱背景网格、调整区域蓝色和边缘光；路线编号按观察距离显示，公开点随距离缩放，减少远景拥挤。
8. 保留省份、城市与站点点击流程：河南进入省域，城市进入市域，黄色/绿色设施点进入对应类型三维场景。未做实景建模的公开设施仍明确使用通用模板。
