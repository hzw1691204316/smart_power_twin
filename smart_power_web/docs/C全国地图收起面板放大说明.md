# C全国地图收起面板放大说明

更新日期：2026-10-15

全国概览、省份与城市地图点击“收起面板”时，当前区域以平滑镜头拉近的方式适度放大；点击“显示面板”恢复当前区域的标准全域视野。保持原来的区域中心、立体/俯视角度、海蓝配色和地图入口。河南全省、18个市域和其他省份轮廓视图均已接入。

实现位置：

- `src/layouts/MapWorkspaceLayout.vue`：通过 `panelsVisible` 双向状态让全国页获知面板是否隐藏；其他页仍由布局内部管理。
- `src/views/OverviewView.vue`、`ProvinceView.vue`、`ProvinceMapView.vue`：把面板状态传给地图的 `expandedView`；省市切换继续遵循当前面板状态。
- `src/components/map/CesiumMap.vue`：响应此状态，按当前全国/省份/城市范围切换构图。
- `src/components/map/cameraView.ts`：全国普通构图填充参数为0.90，收起面板使用1.02；省市普通构图0.86，收起面板使用0.98，保留一些路网边距。参数越大地图越大。复位和视角切换会遵循当前面板状态。

已通过完整 `npm.cmd run verify`。检查覆盖全国、省域、市域及较小区域、不同画布比例、立体与俯视、反复展开/收起距离不累积，确认区域中心及俯仰不随构图变化。登录刷新、用户名、原有城市选择、Vue区块顺序及原地图回归继续通过。

实际浏览器视觉复测仍受此前保存的本地预览权限限制，未完成。刷新前端后可自行切换按钮查看放大幅度；本次未修改后端。
