## 数据来源与处理限制

行政区采用阿里云DataV.GeoAtlas公开资源。高速与设施采用OpenStreetMap，经Geo2Day河南PBF提取，遵循ODbL署名与派生数据许可要求。完整URL和处理规则见public/maps/C地图数据来源与使用说明.md。

收费设施原始点可能表示各车道收费亭，按约700米邻近距离归并后用于省域展示，可能合并相邻双侧设施。面服务区以节点平均位置作定位，不表示入口。无名称点保留未命名提示。844个位置点与官方资产总数不等价。

OSM采用WGS84；行政区坐标依据与时效须向提供者核实。当前原型可用于界面与交互开发，正式业务地图需要核对权威台账、道路通车状态、方向和资源使用条件。不能把省域简化线用于精确里程测量。
