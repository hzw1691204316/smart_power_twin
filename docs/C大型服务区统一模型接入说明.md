# C大型服务区统一模型接入说明

## 现在如何打开
刷新系统后，在全国概览左侧或河南省/地市页面左侧，点击：

**大型服务区模型 · 光伏 / 储能 / 充电 ↗**

不需要查找郑州站，也不需要切换公开位置列表。正常登录后还可以直接访问：
`http://127.0.0.1:5173/templates/service-large`

## 统一分类和适用范围
- 模板编号：`SERVICE_L`。
- 类型：服务区 `SERVICE`；规模：大型 `L`。
- 标准模型路径：`/models/service_large.glb`。
- 资源使用第二版双侧服务区，含154片光伏、12台充电桩、4台储能柜、2台箱式变压器以及逆变器、计量柜、消防柜，共34个能源对象。
- 大型模型不再由郑州站专用代码选择，统一通过模型规模选择，与城市、站名无关。
- 任何未绑定私有台账的公开服务区进入三维后，左侧“服务区模型→预览规模”都可选择中型或大型。选择写入URL，刷新保持。
- 原郑州公开位置默认预览仍设为大型；这里的modelScale只表示预览模板，不能当作真实站点规模的核验依据。其他公开站点未提供规模时保留原中型预览，用户可切换大型。
- 原中型服务区和收费站模型保持原配置；大型收费站、小型模型没有因本次修改而被冒充为已制作。

## 数据说明
大型模型是参考图制作的能源设施方案，不是任何指定站点的实测数字模型。目录状态未知，监测、功率、趋势及告警显示待接入；设备位置和容量需要现场核验。

模型对象的交互ID以当前预览实例ID为前缀，因此不同服务区不会共用设备选择状态。各GLB节点稳定名称保持，可继续用于数据库的设备/测点绑定。

## MySQL模板目录
项目SQL与本说明同目录均提供：`C07大型服务区_统一模板注册.sql`。

网页现在可以直接查看模型，**不需要先导入SQL**。若要让后端 `/api/v1/scene-templates` 返回大型模板的新制作版本，再由用户在已有smart_power_twin数据库中手动执行该脚本：

- 注册SERVICE_L版本20261018，状态PUBLISHED，资源地址/models/service_large.glb。
- 包含资源SHA256、字节数、对象键、布局来源等信息。
- 同一版本重复执行不新增重复模板或审计；如存在不同资源配置则报SERVICE_L_VERSION_CONFLICT，防止覆盖。
- 不修改现有站点规模，不扩大账号站点权限，不替换任何已发布场景、设备或测点绑定。
- 旧模板草稿继续保留。

有真实台账的大型站点应按自身设备、规模和测点创建/发布场景，使用SERVICE_L模板资源；不能把中型站点旧对象键自动套在新模型上。当前版本管理界面主要维护已有场景的版本与绑定，尚不提供从零建立站点场景的完整UI。

## 修改位置
- `smart_power_web/src/data/serviceModelCatalog.ts`：大型服务区统一模板配置和34个对象名称。
- `smart_power_web/src/services/facilityScene.ts`：按预览规模选择模板，第四参数requestedScale优先于设施modelScale，再使用原模板规模。
- `smart_power_web/src/views/SiteView.vue`：独立模型库预览、公开服务区规模下拉框、未接入空态。
- `smart_power_web/src/router/index.ts`：/templates/service-large独立登录后入口。
- `smart_power_web/src/views/OverviewView.vue`、`ProvinceView.vue`：固定可见快捷入口。
- `smart_power_web/public/models/service_large.glb`：统一标准资源。
- `sql/C07大型服务区_统一模板注册.sql`：手动注册后端模板。

此前的郑州专用文件名和代码已统一命名；旧接入说明属于历史记录，以本说明为准。
