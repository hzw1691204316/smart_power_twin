# C站点与设备台账维护：实现与测试指南

更新：2026-10-18。后端版本0.7.0，继续使用现有19表，没有新增数据库表。

## 1. 从哪里进入
登录后，点击右上角用户名 → **站点与设备台账**。

也可以直接打开：`http://127.0.0.1:5173/admin/assets`。

页面左侧为当前账号授权站点，右侧为所选站点的资料与设备，下面是新增/编辑表单；点击维护按钮会滚动到表单。支持搜索和每页20条分页。

有site:read的账号可以查看站点；设备列表还需device:read。观察员没有写入权限，显示只读，不显示新增/编辑按钮。

## 2. 先准备权限和写入条件
已有用户在MySQL手动执行同目录文件：
`C09站点设备台账维护_权限初始化.sql`

脚本只为ADMIN和存在的SIM_ADMIN角色增加：
- `site:create`：新增业务站点。
- `asset:manage`：维护已经授权的站点和设备。

VIEWER、SIM_VIEWER、SIM_OPERATOR不增加写权限；脚本不改账号密码、账号状态、已有站点范围或其他权限。重复执行会补回本脚本声明的权限，主动撤权后不要重跑。

离线全模块素材生成器已包含这两个新权限，生成全新素材库时SIM_ADMIN会获得；原先导入的C01仍可继续使用，用C09补齐即可，不必覆盖旧数据。

执行后重启后端、重新登录。后端本地`.env.mysql.local`的`SPT_MYSQL_ALLOW_WRITES`必须已设置为true，否则接口明确返回409只读提示。这个开关不会由前端或权限脚本自动修改。

后端MySQL连接账号还必须具备现有SELECT权限和以下业务写权限：site/device/site_route_link的INSERT、UPDATE，user_site_scope的INSERT，audit_log的INSERT；其他原模块所需权限保持。应用不会自动执行GRANT。锁定读会使用相关表权限，不能将资产查询账号误认为天然有写权限。禁止用数据库连接密码当网页账号密码。

## 3. 新增站点怎么填
可以先创建一个明确标注模拟的新站验证：

| 字段 | 测试示例 / 说明 |
| --- | --- |
| 业务编码 | TEST_ZZ_SERVICE_01，1—64位英文字母、数字、下划线和短横线；全库唯一 |
| 站点类型 | 服务区SERVICE或收费站TOLL；创建后固定 |
| 来源 | 选择模拟台账；现场资料必须有对应真实资料，创建后固定 |
| 名称 | 郑州测试服务区（模拟），用于展示，不用名称做关联身份 |
| 生命周期 | ACTIVE有效，INACTIVE停用，RETIRED退役；不代表设备在线 |
| 规模 | S小型、M中型、L大型；有任何三维场景后冻结 |
| 省级代码 | 410000或41，保存为410000；不能填410100这样的城市编码 |
| 地市 | 郑州市或郑州；用于当前地市筛选 |
| 经纬度 | 可以同时留空；若为了模拟地图测试填写113.5500000、34.8400000，必须在来源说明中写明为模拟参考点，非实测位置 |
| 坐标来源 | 写明公司台账、现场测量、公开参考或模拟资料 |
| 共同站区分组码 | 有配对站时使用相同分组码，否则留空 |
| 主路线 | 从已有业务路线中选择；未核验留空 |

坐标要求WGS84，最多7位小数，必须成对填写。缺坐标是null，不能用0凑数。已有非WGS84坐标不可直接覆盖为WGS84，必须先核验转换。

创建成功后，当前创建者在同一个事务中获得新站范围，因此可以继续维护。其他管理员/观察员不会自动获得这个新站，需由有账号管理权限且拥有新站范围的人再分配。

如果新增后身份刷新暂时失败，页面会提示“已保存，请刷新页面读取授权”，不要重复点击新增。

## 4. 新站如何进入地图和三维
地图不再只显示旧的六个演示站点。后端授权台账中坐标完整、有效的WGS84站点会加入地图列表，名称、城市、规模、坐标、主路线来自数据库。

- 河南全省页只显示河南台账；地市页按地市名称/原有城市编码筛选。
- 无坐标或非WGS84记录仍能在台账管理查询维护，但不伪造地图点。
- 原有朝歌等前端路由ID保持；新增站点使用`db-site-数据库ID`的前端ID，后端接口仍使用数据库数字字符串。
- 新站没有自动生成的监测读数和设备；地图显示“待接入”，不把占位0当真实功率。
- 新站没有自动生成的发布场景。进入三维时显示“尚无发布场景”，需要使用twin模块明确建立/发布，不能自动套别站设备。
- 选大型L并不代表已经发布大型模型；统一SERVICE_L资源仍可从“大型服务区模型”入口预览。
- 台账资料修改后地图缓存失效，返回地图会重新读取。

## 5. 编辑、停用与身份约束
站点的code、siteType、isDemo创建后固定；不提供迁移历史的隐式改名操作。可编辑显示名、城市、省、坐标、来源、共同站区码、生命周期和主路线。

存在任何三维场景时禁止直接改变规模，返回SCENE_SCALE_LOCKED（409），避免旧模板和发布场景失配。修改坐标或来源后会清除原坐标核验时刻，需要重新核验。

主路线操作只切换主标记：设为另一条路线不会删除原路线、方向或里程；选“未指定”只取消主标记。路线必须已经在业务目录中且有效，当前还没有路线新增/编辑UI。

停用/退役不会删除区域、设备、测点、历史、告警或场景；也不会自动改变其他对象的生命周期、确认/关闭告警。站点停用后禁止新增设备，汇总不再用该站功率。站点台账停用不是采集系统停机命令，已有设备不被级联停用；如需阻止设备采样，应明确维护设备状态与公司采集侧。

同一条资料的编辑当前采用完整保存，服务器按站点锁串行处理；不是乐观版本合并。多人同时编辑同一字段时，后保存的有效请求覆盖先保存值，请在编辑前重读详情。

## 6. 新增和维护设备
先选择有效站点，再点“新增设备”。

| 字段 | 含义 |
| --- | --- |
| 编码code | 站内唯一，其他站允许相同编码；创建后固定 |
| 类型deviceType | 如CHARGER、TRANSFORMER、ESS_CABINET，创建后固定 |
| 系统systemType | PV光伏、ESS储能、GRID配电、CHARGING充电、LOAD负荷、AUX辅助；创建后固定 |
| 模拟身份isDemo | 明确选择，创建后固定；必须与采样来源一致 |
| 区域areaId | 本站区域，下拉可空；不能引用另一站区域 |
| 父设备parentDeviceId | 本站设备ID，可从设备列表复制；可空，不能自指或形成环 |
| 额定功率ratedPowerKw | kW，不是实时功率 |
| 额定电量ratedEnergyKwh | kWh，如储能柜额定电量，不是日用电 |
| 额定容量ratedCapacityKva | kVA，如变压器额定视在容量 |
| 厂家、型号 | 型号不是GLB模型文件名 |
| 生命周期 | ACTIVE、MAINTENANCE、INACTIVE、RETIRED |

额定数值可空，0与空值区分；不能为负，最多四位小数并受数据库精度限制。编辑不会改变站点、编码、设备类型、系统及来源身份。

设备维护/停用/退役后，已有采集接口会按设备状态拒绝新入库；不会删除旧历史、测点或绑定。新增设备没有自动测点，需要在monitoring中维护点表；不会自动出现在旧三维场景，需明确配置对象/设备/测点绑定。

## 7. 后端接口
所有接口需要Bearer；查询按已有规则，新增四个写接口：

| 接口 | 权限与行为 |
| --- | --- |
| POST /api/v1/sites | site:create + site:read；新增站点、创建者范围、审计同事务；201 |
| PUT /api/v1/sites/{siteId} | asset:manage + site:read，且站点在授权范围；完整保存可编辑资料 |
| POST /api/v1/sites/{siteId}/devices | asset:manage + site:read + device:read；本站有效才可新增；201 |
| PUT /api/v1/sites/{siteId}/devices/{deviceId} | 同上权限；必须同站，校验父链/区域 |

ID以字符串传输。无权限403；无/跨站资源404；只读、编码重复、场景规模冻结、父链环409；未知字段/错误值422。没有硬删除接口。

具体请求字段使用camelCase，对应本说明表格及OpenAPI。SiteEdit/DeviceEdit不接受身份字段；不要把查询响应整份原封不动作为PUT请求。

没有删除历史的“清空”按钮。对外部批量导入、站点迁移或把模拟资产改成现场资产，应另外设计迁移审核流程，不能通过编辑一列冒充数据已核验。
